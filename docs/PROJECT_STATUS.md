# 문연 목표와 진행 현황

기준일: 2026-11-20. 이 문서는 현재 소스 코드, 자동 테스트, 로컬 화면 확인을 근거로 작성했다. 장기 목표와 다음 단계는 구현 상태와 구분한 제안이며, 실제 수업 도입이나 교육 효과가 입증되었다는 뜻은 아니다.

## 2026-11-20 시안 업데이트

- AI 모델은 현재 범위에서 제외했다. 서버 기본값은 `MUNYEON_AI_ENABLED=0`이며 학습실·추천 버튼을 숨긴다. 향후 연결 코드는 보존한다.
- 학생의 과제 안내·제출과 교수자의 직접 질문·평가 흐름을 기존 글숲 홈서버의 별도 서비스로 배포했다.
- 무료 HTTPS 주소와 개별 계정, 서버 Node.js 24 테스트, 실제 API 접근 제어·수동 평가 저장·재시작 보존을 확인했다.
- Canvas는 공식 문서로 연동 가능성을 검토했다. 학교 키·LTI 등록·실제 학생 자료 연동은 아직 하지 않았다.
- 아래 초기 기능 표의 AI 관련 항목은 보존된 구현 현황이며 현재 시안 활성 기능이 아니다.

## 프로젝트가 해결하려는 문제

AI를 사용할 수 있는 과제에서 학생이 어떤 도움을 받았고 최종 판단을 어떻게 내렸는지 설명할 수 있도록 한다. 교수자는 과제의 허용 범위를 정하고 제출물의 실제 문단을 근거로 구술 질문을 준비한다. 마지막 평가는 교수자가 학생의 설명을 듣고 직접 기록한다.

전체 대화를 감시하거나 AI 사용 여부를 자동 판별하는 시스템은 현재 목표에 포함하지 않는다. 교수자 화면에는 학습 도움 유형과 학생이 선택해 공유한 답변·자기보고가 표시된다. 서버에는 학습 대화가 저장되므로, 교수자 화면의 열람 제한과 운영자의 데이터 접근 가능성은 구분해야 한다.

## 목표 범위

1. **핵심 MVP:** 교수자 지침 설정 → 학생 AI 학습 → 선택적 사례 공유와 과제 제출 → 문단 기반 질문 작성·확정 → 구술평가 저장까지 연결한다.
2. **소규모 수업 시범 운영:** 디자인을 정리하고 실제 모델·HTTPS 서버·개별 계정·백업 복구를 검증해 한 과제의 수업 흐름을 운영한다.
3. **확장 단계 제안:** 여러 강좌·과제, 명단과 제출 기한, 재제출 정책, 성적 내보내기, 학교 인증·LMS 연동을 다룬다. 학교 협의와 사용성 검토 후 우선순위를 확정한다.

현재 위치는 **AI 없는 서버 시안 배포 및 기본 동작 검증 완료, 실제 수업 운영 준비 전 단계**다. 작업별 규모와 최종 범위가 확정되지 않아 전체 진행률을 임의의 백분율로 표시하지 않는다.

## 현재 구조의 한계

- DB의 과제는 `id=1` 한 건이며, 제출물은 학생당 한 건이다. 여러 과제를 운영하려면 스키마와 API를 변경해야 한다.
- 교수자별 강좌 소유권·수강 명단 분리가 없다. 여러 교수자가 같은 서버에 로그인하면 같은 과제와 제출물에 접근한다.
- 학생은 제출 후 제목과 제출 시각을 확인하지만, 제출 내용 수정·재제출 및 성적 확인 화면은 없다.
- 참고 자료는 텍스트 안내다. 파일 업로드·검색 기반 답변·자동 채점·음성 녹음은 구현하지 않았다.
- 학습 대화와 제출 초안의 상태가 다르다. 대화는 DB에 저장하지만 제출 전 초안과 공유 선택은 브라우저 화면 상태이므로 새로고침하면 사라진다.
- AI 지침은 모델 프롬프트에 전달된다. 실제 모델이 모든 상황에서 지침을 지킨다는 보장은 검증하지 않았다.
- SQLite 단일 앱 인스턴스 구성이며, 실제 동시 접속 수에 대한 성능 목표와 측정값은 없다.

## 이번 확인 기록

- Node.js 26.6.0에서 `npm test`: 통합 테스트 3개 통과.
- 같은 환경에서 `npm run build`: Vite 프로덕션 빌드 성공.
- 프로젝트 요구사항 및 Docker 기준은 Node.js 24 이상이다. 추가 배포 확인에서는 홈서버 Node.js 24.22.1로 동일한 통합 테스트 3개를 통과했다. Docker 컨테이너 실행은 검증하지 않았다.
- 원본 `data/`와 분리한 임시 SQLite에 예시 데이터를 구성해 로컬 Chrome 화면을 확인했다. 예시 AI 답변은 화면 설명용으로 넣었으며 실제 모델 호출 결과가 아니다.
- 화면 캡처는 대화에서만 제시하며 GitHub 업로드 대상에 포함하지 않는다.
